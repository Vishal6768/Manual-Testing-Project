
# Manual Testing Project – SauceDemo

## Project Overview

This repository is an independent Software Quality Assurance
project focused on manual testing of an e-commerce web application.

The project demonstrates a structured QA approach covering
requirement analysis, test planning, test execution,
defect management, Agile processes and quality reporting.

## Application Under Test

- Application: SauceDemo (Swag Labs)
- URL: https://www.saucedemo.com/
- Application Type: E-commerce Web Application
- Testing Type: Manual Testing
- Project Status: In Progress

## Project Objectives

- Understand business and functional requirements.
- Design comprehensive test scenarios and test cases.
- Validate application functionality and business workflows.
- Identify, document and track software defects.
- Perform smoke, sanity and regression testing.
- Validate UI/UX and end-to-end user journeys.
- Maintain structured QA documentation.
- Prepare test execution and quality reports.

## Defect Management Process

New → Assigned → Open → Fixed → Retest → Closed

Defects that fail retesting may be reopened.

Each defect report will include:

- Bug ID
- Bug Title
- Module
- Environment
- Preconditions
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Status
- Supporting Evidence
